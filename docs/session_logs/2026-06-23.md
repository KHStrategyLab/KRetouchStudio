## Runtime Mode Definition Update

- Defined runtime modes as `Viewer`, `Edit`, and `Multi`.
- `Viewer` covers no selection or single-photo viewing with no expanded right retouch tab.
- `Edit` requires exactly one selected photo and one expanded right retouch tab.
- `Multi` starts at two or more selected photos.
- `Multi` blocks right retouch tab entry and save.
- Work-area/tether imports auto-focus only in `Viewer` so new camera captures can advance the single-photo review flow.
- Work-area/tether imports do not steal focus in `Edit` or `Multi`.

## Path-Based Edit History Persistence

- Edit history is now keyed by normalized image file path.
- Selecting another photo stores the current path history before switching.
- Reopening the same path restores its history from memory or local AppData.
- App close stores the current path history under `%LOCALAPPDATA%\KRetouchStudio\EditorHistory`.
- Work-area refresh removes stored path history when that source file is no longer present in the current folder.

## Boundary Probe Preserve Slider v1

- Added `Edge` slider to the Background tab with default value `0`.
- Boundary probe is finder-only and does not cut alpha.
- `Edge 0` keeps the refined MediaPipe alpha unchanged for preserve probing.
- Positive `Edge` values scan the mask boundary with a 30px probe and only raise alpha for likely subject pixels.
- Re-clicking `White` with the same Edge value is a no-op; changing Edge rebuilds the current White history step from the pre-White source.

## Inner Dark Edge Fill v1

- Added a white-background alpha fill pass for dark subject pixels near the inner mask edge.
- The pass only raises alpha and never cuts alpha.
- It targets suit and hair edge pixels that are connected to inner subject support but still have partial alpha.
- Goal is to reduce white inner-edge bands after high Edge preserve values.

## Local Outside Mean Cleanup v1
