## Crop Formula

- Use the approved eye points to compute `eye_center`.
- Use the approved `chin` point as the lower facial reference.
- Let `d = chin_y - eye_center_y`.
- Crop top:
  - `eye_center_y - d`
- Crop bottom:
  - `eye_center_y + (2 * d)`
- Total crop height:
  - `3 * d`
- Crop sides:
  - use detected face box left/right as the reference
  - apply side padding so ears and nearby hair can remain inside the crop

- The crop rectangle is now named `PortraitTrainingCropBox`.
- Purpose:

  - clothing-detection formula verification
- Current policy id:
  - `portrait_training_crop_box_v1`
- Revised formula:
  - `D = ChinY - EyeCenterY`
  - `Top = EyeCenterY - 1.0D`
  - `BottomBase = EyeCenterY + 2.0D`
  - `Bottom = max(BottomBase, ClothingGuideY + 3)`
  - `Height = Bottom - Top`
  - `Width = Height * 2 / 3`
  - `CenterX = EyeCenterX`
  - `Left = CenterX - Width / 2`
  - `Right = CenterX + Width / 2`
- This revision keeps `clothing_start` as a stored approval point and uses it as a lower safety guide for crop height.
