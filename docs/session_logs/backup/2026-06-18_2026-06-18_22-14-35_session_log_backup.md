## Toolbox / Retouch Panel Boundary Decision

- Final direction:
  - Toolbox defines the work target.
  - Retouch panel sends values to the engine.
- Toolbox owns:
  - work area
  - selection
  - mask source
  - brush stroke
  - path
  - sample
  - crop rectangle
- Retouch panel owns:
  - amount
  - strength
  - radius
  - color
  - opacity
  - blend mode
  - preset
  - operation parameters
- A retouch slider must not silently invent a hidden target.
- If an operation uses an automatic target, the detector or default target must be named.
- Added `docs/TOOLBOX_RETOUCH_PANEL_CONTRACT.md`.
- Linked the contract from `docs/README.md` and `docs/SCREEN_IO_AND_WORK_MODE_ARCHITECTURE.md`.
