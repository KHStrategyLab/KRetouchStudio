## Face Up/Dn 3D Direction Lock

Approved direction:

- `Facial Reshape > Head Pose > Up/Dn` is not a flat 2D vertical push.
- The engine must not chase exact lens millimeters or exact subject distance from one 2D portrait.
- The practical target is visual naturalness, fast preview, and stable fallback behavior.
- MediaPipe 478 landmarks and relative z values are detector data, not a calibrated full 3D scan.

New rule document:

- `docs/FACE_UPDN_3D_PROJECTION_RULE.md`

Core path:

```text
cached MediaPipe landmarks
-> shallow z correction
-> portrait-camera assumption
-> BackProject
-> Pitch Rotate
-> Project
-> validate with all source/projected debug points
-> then expand to face-line mesh
-> only then attempt pixel warp
```
